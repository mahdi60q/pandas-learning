# Pandas Learning

A practical collection of Jupyter Notebooks for learning and practicing Pandas.

## Overview

This repository contains hands-on examples covering essential Pandas concepts, including DataFrame operations, data conversion, filtering, querying, datetime operations, data transformation, and more.

The notebooks are organized by topic to make the learning process easier to follow and review.

## Topics Covered

- DataFrame Basics
- Data Conversion
- DataFrame Options, Styling & Profiling
- Renaming Columns
- DataFrame Equality
- Querying Data
- Splitting Columns
- Apply, Map & Custom Functions
- Zip and Tuple Operations
- Column Selection
- Numeric Conversion
- Data Filtering
- Date and Time Operations
- Exploding Columns
- Ordered Categorical Data
